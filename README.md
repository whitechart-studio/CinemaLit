# CinemaLit Studio 🎬

> **Agentic pre-production for film.**
> Upload a screenplay. Get a costed scene breakdown, cast list, shot list,
> budget, shooting schedule and AI storyboards — generated by an autonomous
> Director Agent, stored in ClickHouse, and explorable in a film-tool-shaped
> web workbench.

Built for the **Google Gemini + ClickHouse "Agentic Cinema"** track.

---

## What it does

Pre-production on a low-budget film is a week of clerical work that is entirely
derivable from the script. CinemaLit inverts it: the Director states intent, the
agent does the reasoning, the human reviews and approves.

Upload a script and the Director Agent:

1. splits it into scenes (regex — free, no tokens),
2. breaks every scene down individually — synopsis, INT/EXT, time of day, page
   count, risk level, cast with day rates, props/wardrobe/VFX/SFX/stunts with
   costs and vendors, and a shootable shot list with lenses and framings,
3. derives budget lines straight from the breakdown, so they always reconcile,
4. packs scenes into shoot days grouped by location and time of day,
5. optionally generates timed AI storyboard frames with real generated images,

…writing all of it into ClickHouse, with live progress in the browser the whole
time. A 30-scene script goes from upload to a fully populated production
database in minutes.

## Architecture

```text
Browser  (React 19 + TypeScript + Vite, zustand)
   │  REST + JWT
   ▼
web/server.py   (Python stdlib threaded HTTP server, :8000)
   │            serves the built SPA + the JSON API
   │
   ├── auth / read endpoints ─────────► ClickHouse Cloud
   │
   └── every AI endpoint
          ▼
   cinemalit_agent  (Google ADK)
      root_agent "cinemalit_director" — 27 tools
        ├─ 13 production-db tools (read/write scene, budget, cast, shot, schedule)
        ├─ 12 crew tools        (risks, breakdown, budget, schedule, ops,
        │                        governance, audit, studio memory)
        └─ 2  pipeline tools    (ingest script, generate storyboards)
             ├─ breakdown_agent   — schema-constrained, no tools
             ├─ storyboard_agent  — schema-constrained, no tools
             └─ pollinations.ai (flux) → storyboard JPEGs
                     ▼
              ClickHouse Cloud  (all writes)
```

**Stack:** React 19 · TypeScript · Vite 8 · zustand · Python 3.11 (stdlib HTTP,
no web framework) · Google ADK · Gemini · ClickHouse Cloud.

## Quickstart

### 1. Configure

```bash
cp .env.example .env
cp cinemalit_agent/.env.example cinemalit_agent/.env
```

Fill in `GOOGLE_API_KEY`, the `CLICKHOUSE_*` values and a long random
`JWT_SECRET`. Keep the ClickHouse values identical in both files — the agent's
`.env` overrides the root one for anything the agent reads.

For **ClickHouse Cloud**, set `CLICKHOUSE_SECURE=true` (the port then defaults
to 8443). For **local ClickHouse**, `docker compose up -d` brings one up on
8123 and `CLICKHOUSE_SECURE` stays false.

### 2. Install

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e .          # Linux/macOS: .venv/bin/python
.venv/Scripts/python.exe -m pip install -r cinemalit_agent/requirements.txt
```

### 3. Create the schema

```bash
python scripts/migrate_v2.py
```

⚠️ Destructive — it drops and recreates the six production tables. Run it
against an empty or expendable database. `users`, `storyboards`,
`governance_gates` and `agent_audit_log` are preserved.

### 4. Build the frontend and run

```bash
cd cinemalit-studio && npm install && npm run build && cd ..
python -m web.server
```

Open **http://localhost:8000**, register an account, and click **New Project**.

For frontend development with hot reload, `npm run dev` in `cinemalit-studio/`
serves on :5173 (the API still needs `python -m web.server` running).

## The workbench

Nine views over one project, all backed by live ClickHouse data:

| View | What it shows |
| --- | --- |
| **Scene Canvas** | The scene graph — draggable nodes with slugline, pages, risk, cast, shoot day; pan/zoom/minimap/auto-arrange |
| **Screenplay** | Formatted reader + Fountain editor, import `.fountain`/`.txt`/`.md`/`.fdx`/`.pdf`, export `.fountain`, and re-ingest an edited script |
| **Storyboard** | Per-scene AI keyframe sequences with director-controlled interval, lens and custom prompt |
| **Breakdown** | Classic breakdown sheet — cast, props, wardrobe, VFX, SFX per scene, colour-coded by INT/EXT + time of day |
| **Stripboard** | Shooting schedule strips by shoot day, with a day-out-of-days grid |
| **Shot List** | Every shot with type, angle, movement, lens and status |
| **Budget** | Topsheet — account, category, estimated vs cap, over/ok |
| **Call Sheet** | Per shoot day: scenes, pages, cast called, hazards, printable |
| **SQL Console** | A real ClickHouse console in-app — schema browser, presets, Ctrl+Enter to run — plus natural-language "ask the data" |

The **Director Agent chat** sits on the left rail throughout, scoped to the
active project, with quick prompts and a one-click DGA schedule compliance
audit.

## API surface

All `/api/*` routes require a bearer JWT except register, login, google, status
and ping.

| Method | Path | Purpose |
| --- | --- | --- |
| POST | `/api/auth/register` · `/login` · `/google` | accounts, returns JWT |
| GET | `/api/auth/me` | current user |
| GET | `/api/status` | Gemini state, active model, agent flag, ClickHouse state |
| GET | `/api/projects` | list projects |
| POST | `/api/projects` | create + start agent ingest (202) |
| POST | `/api/projects/storyboards` | whole-project storyboard run (202) |
| GET | `/api/jobs` | background job progress |
| GET | `/api/clickhouse/scenes` · `/shots` · `/budget` · `/stats` · `/schema` · `/ping` | project data |
| POST | `/api/clickhouse/query` | SELECT-only console query |
| POST | `/api/ai/chat` | Director Agent chat |
| POST | `/api/ai/analyze-script` | script risk analysis |
| POST | `/api/ai/ask-data` | natural-language question over the DB |
| POST | `/api/ai/sync-script-to-db` | store edited script + re-ingest (202) |
| POST | `/api/ai/dga-check` | DGA schedule compliance audit |
| POST | `/api/ai/generate-storyboard` | regenerate one scene's boards |

## Agent tools

The Director Agent carries 27 tools:

**Production database (13)** — `query_production_db` (SELECT-only),
`get_scene_details`, `get_scene_script`, `get_project_budget`,
`add_scene_element`, `delete_scene_element`, `add_budget_item`,
`delete_budget_item`, `add_cast_member`, `remove_cast_member`, `add_shot`,
`delete_shot`, `reschedule_scene`.

**Crew (12)** — `analyze_script`, `list_scenes`, `find_risks`,
`production_breakdown`, `estimate_budget_pressure`, `suggest_budget_savings`,
`generate_schedule`, `create_production_tasks`, `request_gate_approval`,
`get_audit_log`, `ask_gemini_direct`, `query_studio_memory`.

**Pipeline (2)** — `ingest_project_script`, `generate_project_storyboards`.

Per-scene breakdown and storyboarding are delegated to two small
schema-constrained sub-agents with no tools, so bulk work doesn't re-send 17
tool declarations per scene.

## Data model

ClickHouse database `cinemalit`. Every table except `users` is scoped by
`project_id`; production tables are `ReplacingMergeTree` (reads use `FINAL`).

`projects` · `jobs` · `scenes` · `cast_members` · `scene_cast` · `elements` ·
`shots` · `budget_items` · `storyboards` · `users` · `governance_gates` ·
`agent_audit_log`

## Legacy CLI

The original terminal interface still works and is kept as a local, offline
dev/demo fallback. It is **not** the product path — the web app plus the ADK
agent is. Its crew logic (`cinemalit/crews/`) is still load-bearing: the agent's
12 crew tools run it unchanged against ClickHouse.

```bash
chmod +x bin/* && export PATH="$PWD/bin:$PATH"

cinemalit init "Neon Echoes"
cinemalit ingest scripts/sample_script.fountain
cinemalit direct "Turn this into a 2-day shoot plan under $5k"
cinemalit status
cinemalit approve gate-budget-cap

cinemalit mcp serve-all      # stdio MCP server for external MCP clients
```

Departmental CLIs: `cinemalit-story`, `cinemalit-production`,
`cinemalit-budget`, `cinemalit-schedule`, `cinemalit-ops`,
`cinemalit-governance`.

## Configuration reference

| Variable | Where | Default | Purpose |
| --- | --- | --- | --- |
| `GOOGLE_API_KEY` | both | — | Gemini auth |
| `GEMINI_MODEL` | both | agent's wins | text model |
| `GEMINI_IMAGE_MODEL` | agent | `gemini-2.5-flash-image` | storyboard images |
| `CLICKHOUSE_HOST/PORT/USER/PASSWORD/DATABASE` | both | localhost:8123 | database |
| `CLICKHOUSE_SECURE` | both | `false` | HTTPS + port 8443 when true |
| `JWT_SECRET` | root | random per boot | session signing — set it, or restarts log everyone out |
| `USE_ADK_AGENT` | root | `true` | route AI handlers through the agent |
| `CINEMALIT_WEB_PORT` | root | `8000` | server port |
| `PIPELINE_WORKERS` | agent | `6` | concurrent scene breakdowns |
| `PIPELINE_IMAGE_WORKERS` | agent | `2` | concurrent image calls (429-sensitive) |
| `ADK_AGENT_VERBOSE` | agent | `true` | print agent tool calls to the console |
| `ADK_AGENT_LOG_FILE` | agent | — | redirect that output to a file |
